# Данные

Файл `telco_churn.csv` — Telco Customer Churn, тот же набор, что в паспорте
практики 2 и в ноутбуке практики 3.

- **Источник:** Kaggle, `blastchar/telco-customer-churn`, лицензия CC BY 4.0.
- **Объём:** 7043 строки × 21 колонка; после удаления строк с повторяющимся
  профилем — 6970 строк (33 группы профилей, 73 строки, в 18 группах исход разный).
- **Ключ:** `customerID` (уникален).
- **Целевая переменная:** `Churn` — `Yes` ушли (1869 клиентов, 26,54% до чистки;
  1829, 26,24% после), `No` остались.
- **Особенность:** `TotalCharges` хранится текстом, 11 пустых значений у клиентов
  с `tenure = 0`. `train.py` приводит колонку к числу, заменяет пустые на 0,
  добавляет флаг `новый_клиент` и удаляет дубли по признакам до сплита.

Файл в репозитории нужен, чтобы `python train.py` воспроизводил модель
без скачивания данных с Kaggle.
